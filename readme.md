# 🎰 행운의 로또 번호 생성기

파이썬(Python)과 Streamlit 프레임워크를 활용하여 만든 시각적이고 직관적인 웹 기반 로또 번호 생성기입니다. 

## ✨ 주요 기능

*   **랜덤 번호 추출**: 1부터 45까지의 숫자 중 중복 없는 6개의 번호를 랜덤으로 추출하여 오름차순으로 보여줍니다.
*   **다중 세트 생성**: '로또번호 생성' 버튼을 누를 때마다 새로운 번호 세트가 추가되며, 최대 5세트까지 화면에 표시됩니다.
*   **실제 로또 공 색상 적용**: 실제 동행복권 추첨에 사용되는 공 색상 규칙을 적용하여 시각적인 재미를 더했습니다.
    *   1 ~ 10: 노랑
    *   11 ~ 20: 파랑
    *   21 ~ 30: 빨강
    *   31 ~ 40: 회색
    *   41 ~ 45: 초록
*   **초기화 기능**: '초기화' 버튼을 통해 화면에 생성된 번호들을 지우고 처음부터 다시 시작할 수 있습니다.

## 🚀 설치 및 실행 방법

### 1. 요구 사항 설치
터미널(또는 명령 프롬프트)을 열고 프로젝트 폴더로 이동한 후, 아래 명령어를 실행하여 필요한 라이브러리를 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. 프로그램 실행
설치가 완료되면 아래 명령어를 입력하여 프로그램을 실행합니다.

```bash
streamlit run app.py
```

### 3. 사용하기
명령어를 실행하면 기본 웹 브라우저가 자동으로 열리며 로또 번호 생성기 화면이 나타납니다. '로또번호 생성' 버튼을 클릭하여 행운의 번호를 확인해 보세요!
